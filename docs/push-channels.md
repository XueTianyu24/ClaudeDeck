# 手机推送渠道配置指南

ClaudeDeck 支持把「任务完成 / 等待授权」推送到手机，**应用不用开着也能收到**（靠 Claude Code 原生 hook 在会话进程内触发）。两个渠道按平台选，在应用里 🔔 →「📱 手机推送」选择即可。

| 渠道 | 适合 | 成本 | 配置难度 |
|---|---|---|---|
| **Bark** | iPhone | 完全免费 | ⭐ 最简单 |
| **PushPlus** | 微信（安卓 / 全平台） | 实名约 4 元，之后免费 | ⭐⭐ |

**怎么选**：iPhone 用 Bark（免费）；安卓 / 想用微信收的用 PushPlus（一次性实名约 4 元，之后日常免费）。**两个也可以同时填**——任务完成时 iPhone 和微信会一起收到，各自独立互不影响。

配置完成后，**新开一个 Claude Code 会话**让 hook 生效，派个 ≥30 秒的活试试。两个渠道都依赖系统自带的 `curl.exe`（Win10 1803+ / Win11 自带）。

---

## Bark（iPhone，推荐 iPhone 用户）

1. iPhone App Store 搜 **Bark** 安装，打开 App 首页有你的专属地址 `https://api.day.app/<KEY>/`。
2. 复制其中的 `<KEY>`。
3. 应用里渠道选 **Bark**，粘贴 Key → 点「测试推送」，iPhone 收到即配好。

完全免费、无需注册账号。

---

## PushPlus（微信，推荐安卓 / 想用微信收的用户）

微信触达率最高，但有一个**一次性实名门槛**，看清楚再决定。

### 步骤

1. 微信搜公众号 **「pushplus 推送加」**（主体：苏州破壳网络科技有限公司）关注；或浏览器打开 [pushplus.plus](https://www.pushplus.plus) 用微信扫码登录。
2. **完成实名认证**（见下方「关于收费」）。
3. 在「一对一推送」页面复制你的 **token**。
4. 应用里渠道选 **PushPlus**，粘贴 token → 点「测试推送」，微信收到即配好。

> ⚠️ **收不到消息？先查这两点**：
> 1. **关掉服务号的「消息免打扰」**——微信里进「pushplus 推送加」公众号 → 右上角设置 → 关闭「消息免打扰」，否则推送到了但微信不提醒，最常见的坑。
> 2. 测试时若提示 `code:999 请勿频繁推送相同内容`，说明 token 是好的、链路已通，只是相同内容被去重拦了，换个内容或等一会儿即可。

### 关于收费（重要）

- **实名认证是强制的**：2024 年 8 月起，未实名无法调用发送接口（会报错 905）。
- **实名要花钱**：PushPlus 对接第三方渠道做实名校验，**每次校验收取小额费用**（无论成功失败都收）。
- **省钱替代**：**开通一个月会员可免费实名**——相当于花一个月会员费、顺带把实名做了。
- **实名之后日常免费**：免费用户微信推送 **200 条/天**、限频 1 分钟 5 次，对任务完成通知完全够用（会员是 2000 条/天、10 秒 5 次）。

> 一句话：有个一次性的实名小门槛（约 4 元），过了之后日常零成本。iPhone 用户介意付费的话直接用 Bark（完全免费）。
>
> 具体费用以 [PushPlus 实名认证页](https://www.pushplus.plus/doc/function/verify.html) 实时显示为准。

## 工作原理

应用「安装」时会往 `~/.claude/settings.json` 写三个 hook（改前自动备份，可一键卸载），并在 `~/.claude/hooks/` 放一个推送脚本：

- `UserPromptSubmit`：记录本轮起点时间
- `Stop`：算任务时长，满阈值（默认 30 秒，过滤短问答）才推「✅ 任务完成 · 用时 X」
- `Notification`：Claude 卡着等授权时推「⏳ 需要你处理」
